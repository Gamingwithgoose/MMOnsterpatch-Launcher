# MMOnsterpatch Launcher
Closed source launcher for MMOnsterpatch

# How to Use the MMOnsterpatch Launcher

Welcome to the MMOnsterpatch public test! This launcher is used to start Monsterpatch in online mode and connect to the official test server.

## Before You Start

Make sure you have:

- A legitimate Steam copy of Monsterpatch installed
- The MMOnsterpatch Launcher downloaded
- An internet connection
- A MMOnsterpatch account, or be ready to create one

## Getting Started

1. **Extract the launcher files**

   Download the launcher zip and extract it somewhere easy to find, such as your Desktop or a Games folder.

2. **Run the launcher**

   Open the launcher application.

   If Windows shows a security warning, choose **More info**, then **Run anyway**.

3. **Log in or register**

   Use the account section in the launcher to either log in or create a new MMOnsterpatch account.

4. **Install or update the online files**

   Use the launcher to prepare your game for online play.

   Let it finish before starting the game.

5. **Start Online Play**

   Click **Online Play** from the launcher.

   Monsterpatch should open with the online MMOnsterpatch setup active.

6. **Choose your online save**

   On the title screen, log in if needed, then choose an online save slot.

   Your online character is separate from your normal offline save.

## Playing Online

Once you are in-game, you can:

- See other online players
- See other players’ followers
- Find shared overworld spawns
- Interact with online features as they become available
- Request battles with nearby players

To request a battle, stand next to another player and face them before interacting.

## Important Notes

This is a public test build, so bugs may happen.

Known things to keep in mind:

- Some online systems are still being tested
- Prize crystal spawns may still have some cleanup issues after relogging
- If something looks wrong, try closing the game and reopening it through the launcher
- Please report bugs with as much detail as possible

Helpful bug report details include:

- What you were doing
- Where you were in-game
- Whether another player was nearby
- What happened
- What you expected to happen
- Any screenshots or logs if available

## Closing the Game

When you are done playing, close Monsterpatch normally.

If you run into connection issues later, reopen the game through the MMOnsterpatch Launcher instead of launching directly through Steam.

## Offline Play

For normal offline Monsterpatch gameplay, launch the game normally through Steam.

Use the MMOnsterpatch Launcher when you want to play online.
