MMOnsterpatch v0.17.1.5 Authoritative PvP Replay Hotfix

Baseline: v0.17.1.4 PvP Turn + World Presence Desync Hotfix.

Purpose:
- Restore the old MMOnsterpatch real PvP model in the current server/client stack.
- Prevent both clients from waiting on each other.
- Preserve exact command/target/damage replay.
- Eliminate local/random PvP fallback damage.

Changed:
- Removed the failed local-turn token gate from player-side BattleStepStartOfTurn.
- Local player turns now run through vanilla BattleSystem again.
- Enemy-side turns remain network-driven and wait for remote BATTLE_CMD/BATTLE_HIT/BATTLE_DONE.
- Added deterministic GetNextBattler patch while PvP is active.
- Added InitBattle initial-turn alignment so requester-side first alive slot acts first on both clients from mirrored perspectives.
- Kept SelectMove auto-target BATTLE_CMD send for non-manual-target moves.
- Improved manual target packet fallback so selected target slot falls back to the clicked/selected slot if selectedMonIndex is not populated.
- Removed enemy-side local fallback move selection when BATTLE_CMD is missing.
- Removed authoritative-hit timeout fallback that could continue without real BATTLE_HIT/BATTLE_DONE.

Preserved:
- v0.17.1.1 Trading Post save-session hotfix.
- v0.17.1.2 server-truth saves.
- v0.17.1.3 save-select appearance metadata.
- v0.17.1.4 remote avatar stale tolerance increase.
- Ranked PvP foundation remains present, but normal PvP should be tested first.
